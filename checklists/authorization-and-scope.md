# Authorization & scope checklist

Complete before ANY analysis. Keep it in the job folder.

- [ ] The user states ownership or authorization basis (own code / malware triage / sanctioned audit / research on public malware corpus)
- [ ] If the target is a third-party commercial script: STOP unless analyzing it strictly for personal safety (e.g. "is this free model malicious?") — never deliver their reconstructed source for distribution or incorporation
- [ ] Deliverable scope agreed: understand-only / restoration / malware report — not "bypass their licensing"
- [ ] Roblox ToS and local law acknowledged as applicable; no use against live experiences/users without authorization
- [ ] Sandbox exists for any dynamic step (VM/container, no network, no Roblox session, no credentials)
- [ ] Original file preserved read-only; work in `work/`
- [ ] This checklist filed in the job folder

If any box is unchecked and cannot be checked, the task does not proceed; escalate to the user in writing.
